## ◈ System Architecture

The way I think about AI projects:

```mermaid
flowchart LR
    A[Problem] --> B[Data]
    B --> C[EDA & Preprocessing]
    C --> D[Features]
    D --> E[Model]
    E --> F[Evaluation]
    F --> G{Good enough?}
    G -- No --> C
    G -- Yes --> H[Persistence]
    H --> I[API / Application]
    I --> J[User]
    J --> K[Feedback]
    K --> C
```

The goal is not simply **high training performance**.

The goal is a system that can be **understood, evaluated, used, improved, and eventually deployed**.
