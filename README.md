### 06 — HOW I THINK ABOUT AN ML SYSTEM

</div>

<img src="./assets/ml-architecture.svg" width="100%" alt="Machine learning engineering architecture">

~~~mermaid
flowchart LR
    P["01 / PROBLEM"] --> D["02 / DATA"]
    D --> E["03 / EXPLORE"]
    E --> F["04 / FEATURES"]
    F --> M["05 / MODEL"]
    M --> V["06 / VALIDATE"]
    V --> Q{"07 / READY?"}
    Q -- "iterate" --> E
    Q -- "yes" --> S["08 / SHIP"]
    S --> U["09 / USER"]
    U --> R["10 / FEEDBACK"]
    R --> E
~~~

| DATA | MODEL | XAI | SOFTWARE |
|:--:|:--:|:--:|:--:|
| Validate before trusting. | Compare before choosing. | Explain before claiming. | Package before shipping. |
